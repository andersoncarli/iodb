# [1.3] Matriz de concorrencia multi-processo: eixos format/reduce/close/seed

Varre a matriz format x reduce x seed x close sob escrita concorrente multi-processo e registra o comportamento de cada celula — o reprodutor do sprint 002 so cobria um ponto.

## Objetivo

O reprodutor do sprint 002 (`io-engine.concurrency.test.js`) cobriu um ponto só:
`seed=true`, `jsonl`, `append`. Esta feature varre a **matriz** de combinações de pares
`iodb` sob escrita concorrente multi-processo e registra o comportamento de cada célula —
correções de bugs achados aqui viram features próprias (1.4).

Eixos: `format` (`dash`|`jsonl`) × `reduce` (`append`|`merge`) × `seed` (`true`|`false`)
× `close` (`1`|`0`). Cada célula: 8 processos `bun` × 30 writes no mesmo `IO()`.

## Resultado

`io-engine.matrix.test.js` — 6 células, `Bun.spawn` real. Ver requisitos para os achados;
o report do sprint 003 tem a tabela completa e os dois residuais encaminhados a 1.4
(genesis não-atômico; `f.yaml + '.tmp'` fixo).
